# Documentation

This repository separates delivered behavior from proposed design and planned work.

| Layer | Purpose |
| --- | --- |
| [System specs](system-specs/README.md) | Delivered, observable truth |
| [Design](design/README.md) | Proposed and accepted design decisions |
| [Task specs](task-specs/README.md) | Planned work and completed work history |

When a task is completed, update its task record and any affected system spec in the same change.
