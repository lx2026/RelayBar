# Task 071 — 2.0.0 Beta 1 pre-releases

Status: In progress — started 2026-11-17. [Verification](../verification/071-2.0.0-beta-1-pre-releases.md).

## Outcome

RelayBar 2.0.0 Beta 1 (build 26) and Frame 2.0.0 Beta 1 (build 20) are public GitHub pre-releases, and the website and READMEs offer them beside stable 1.6.0.

## Delivery Boundary

Two notarized archives, two pre-release tags, release notes, website, READMEs and changelog. The owner asked on 2026-11-17 for a 2.0.0 beta of both apps, ahead of the native and live-host acceptance of Tasks 067–070. The Sparkle feed, `docs/appcast.xml`, the stable download and the Homebrew cask stay on 1.6.0. Versions do not change; only build numbers rise.

## Work

- Raise the build numbers to RelayBar 26 and Frame 20 on merged `main`, notarize each app from that commit, verify clean extractions and install both locally.
- Publish `frame-v2.0.0-beta.1` with `Frame.zip` first, not marked latest, then `v2.0.0-beta.1` with `RelayBar.zip`, both as pre-releases, and compare an anonymous download of each with the verified archive.
- Once both downloads resolve, publish the website, README and changelog changes.

## Acceptance

- Each pre-release holds one archive whose bytes equal the notarized, stapled archive verified locally; its notes give the compatible pair, the minimum macOS, the checksum and the known limits.
- `v1.6.0` is still the repository's latest release, and `docs/appcast.xml` and the Homebrew cask are unchanged.
- Every beta link on the website and in the READMEs resolves.
