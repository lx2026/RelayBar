How it works

From command
to one click.

RelayBar parses typed forwarding arguments without invoking a shell, turns them into a visible profile, and keeps the controls in your menu bar.

  1. 01

    Paste your SSH command

    Import repeated or mixed -L, -D, and -R rules.

  2. 02

    Review and save

    Name the profile, check each typed endpoint, and optionally place it in a group.

  3. 03

    Connect from the menu bar

    Start, stop, retry, and open supported endpoints without keeping a Terminal tab around.

What’s new in 1.6.0

More control,
fewer surprises.

Choose how often SSH reconnects, undo a pending delete, and preview more files without leaving RelayBar.

01

Retries at your pace

Exponential backoff and a saved retry limit. Set it to zero to turn automatic reconnects off.

02

Five seconds to undo

Single and bulk file deletion wait before reaching the server. Undo during the countdown to keep your files.

03

JSON and video previews

Read selectable JSON and play MP4 files with native controls. Uploads show byte and percentage progress.

04

Clearer at every width

Distinct paths, compact endpoints, and profile forms that explain exactly what needs fixing.

Deliberately small

Your SSH setup
stays yours.

RelayBar manages visible typed forwarding rules over one SSH connection per profile. It doesn’t add an account, analytics SDK, background service, or replacement SSH stack.

It runs /usr/bin/ssh and /usr/bin/sftp directly, so your existing config, keys, known hosts, and SSH agent remain the source of truth.
