RelayBar 2.0,
now with Frame.

2.0.0 is the first version where RelayBar and Frame ship as a pair. RelayBar keeps your tunnels and the SSH connection. Frame reads folders of images, video, Markdown and HTML, on your Mac or on your server through RelayBar.

RelayBar 2.0.0 Beta 1

A flatter popover, Settings in its own window, a Plugins window and a new icon. The menu-bar mark dims when no tunnel is running and adds an exclamation mark when one fails. Needs macOS 13 or later.

Frame 2.0.0 Beta 1

A reader for folders of mixed files, on your Mac or on your server: a folder tree, an outline for Markdown and a mark on files changed since you last opened them. Needs macOS 14 or later.

Review in Frame.

Frame reads folders of images, video, Markdown and HTML. Open a folder on your Mac, or choose Open in Frame in RelayBar’s Remote Files to read one on your server through RelayBar’s connection. Nothing is imported.

Frame is in beta: download Frame 2.0.0 Beta 1 or read its release notes. It needs macOS 14 or later. Its remote folders need RelayBar 2.0.0 Beta 1; an older RelayBar is refused.

01 · Frame

An outline beside rendered Markdown, a Source view for Markdown and HTML, and a dot on each file changed since you last opened it.

Switch optional features in each app’s Plugins window and see what each one needs. Paper Appearance, on by default, gives both apps the same warm colours; turn it off for standard macOS colours.

How it works

From command
to one click.

RelayBar parses typed forwarding arguments without invoking a shell, turns them into a visible profile, and keeps the controls in your menu bar.

  1. 01

    Paste your SSH command

    Import repeated or mixed -L, -D, and -R rules.

  2. 02

    Review and save

    Name the profile, check each typed endpoint, and optionally place it in a group.

  3. 03

    Connect from the menu bar

    Start, stop, retry, and open supported endpoints without keeping a Terminal tab around.

quick_add.profile new profile
What’s new in 1.6.0

More control,
fewer surprises.

Choose how often SSH reconnects, undo a pending delete, and preview more files without leaving RelayBar.

01

Retries at your pace

Exponential backoff and a saved retry limit. Set it to zero to turn automatic reconnects off.

02

Five seconds to undo

Single and bulk file deletion wait before reaching the server. Undo during the countdown to keep your files.

03

JSON and video previews

Read selectable JSON and play MP4 files with native controls. Uploads show byte and percentage progress.

04

Clearer at every width

Distinct paths, compact endpoints, and profile forms that explain exactly what needs fixing.

Deliberately small

Your SSH setup
stays yours.

RelayBar manages visible typed forwarding rules over one SSH connection per profile. It doesn’t add an account, analytics SDK, background service, or replacement SSH stack.

It runs /usr/bin/ssh and /usr/bin/sftp directly, so your existing config, keys, known hosts, and SSH agent remain the source of truth.
