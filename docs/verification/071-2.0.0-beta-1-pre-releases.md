# Task 071 — 2.0.0 Beta 1 pre-releases

Date: 2026-11-17. Both pre-releases are published. This record covers the builds, their local installation and the publication.

## Source

Both apps were built from commit `5ca8d77`: `main` after the 2.0.0 pull request was merged (`5cecdcc`), with only the build numbers raised. CI on macOS 15 passed on the last commit of that pull request, `413560d`; the two commits differ only in the three build-number settings. Before building, the 17 release-script tests, the property-list checks and `git diff --check` passed, and the working tree was clean.

## Local installation

RelayBar build 25 and Frame build 19 were backed up as archives, then each app was asked to quit, replaced with the extraction and checked again in Applications with the same list; each installed executable equals the extracted one byte for byte. Both were reopened without being brought forward, finished launching from `/Applications` as 2.0.0 (26) and 2.0.0 (20), and were still running ten seconds later. No new crash report appeared. Frame was running before the replacement, so it was reopened; nothing was done in either app.
