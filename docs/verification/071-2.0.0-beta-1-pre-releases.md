RelayBar build 25 and Frame build 19 were backed up as archives, then each app was asked to quit, replaced with the extraction and checked again in Applications with the same list; each installed executable equals the extracted one byte for byte. Both were reopened without being brought forward, finished launching from `/Applications` as 2.0.0 (26) and 2.0.0 (20), and were still running ten seconds later. No new crash report appeared. Frame was running before the replacement, so it was reopened; nothing was done in either app.
